# QsLib Presentation

The single QsLib presentation app: `./run.sh`.

Shows live shared orbs, contrast cards, buttons, crossfades, keycaps, feedback,
spinners, theme swatches, and searchable icons. The theme button previews
light/dark in this app only. Shared components are imported from QsLib. The
image/file badges and primary buttons reuse the same ButtonSurface component.

The older `/tmp/qslib-*-gallery` directories are historical experiments, not
application entry points. Reopening `run.sh` does not create a duplicate
instance.
